2 · La tienda: cómo se muestra un producto y cómo se compra

Todo es estático: la página lee el catálogo y cada botón de "Comprar" abre una conversación de WhatsApp con el mensaje listo.

sequenceDiagram
  participant Nav as Navegador
  participant CD as Netlify CDN
  participant P as products.json
  participant WA as WhatsApp

  Nav->>CD: GET / (index.html)
  CD-->>Nav: página + CSS/JS
  Nav->>CD: GET /products.json
  CD-->>Nav: lista de productos
  Nav->>Nav: pinta tarjetas (foto, precio S/, stock)
  Nav->>WA: wa.me/51...?text=Hola, me interesa <producto>
  WA-->>Nav: conversación abierta ✓

4 · Cómo entra el editor y publica productos

La persona editora entra a /admin/ (solo con rol editor/admin), edita en el CMS, y "Publicar" genera un commit a GitHub que reconstruye el sitio.

sequenceDiagram
  participant Ed as Editora
  participant Edge as Netlify Edge
/admin/ por rol
  participant CMS as Decap CMS
  participant GW as Git Gateway
  participant GH as GitHub main
  participant B as Netlify Build
  participant Site as Tienda /

  Ed->>Edge: GET /admin/
  Edge-->>Ed: pagina del CMS (si editor/admin)
  Ed->>CMS: edita producto
  CMS->>CMS: "Guardar" = borrador (rama cms/*)
  Ed->>CMS: "Publicar"
  CMS->>GW: commit + merge a main
  GW->>GH: push a main
  GH->>B: build automatico (~1 min)
  B->>Site: publica public/ actualizado
  Ed->>Site: recarga y ve el cambio ✓

5 · Avisos por correo (sin tocar nada)

Cada registro nuevo y cada edición publicada dispara un email automático a la cuenta de Netlify de la dueña.

flowchart LR
  A[Se registra alguien] --> F1[identity-signup]
  F1 --> GM1[Form nueva-cuenta] --> M1[Email: nuevo registro]
  B[Se publica una edición
de producto] --> F2[deploy-succeeded
filtra mensajes del editor]
  B ~~~ BB[Netlify Build termina]
  BB --> F2
  F2 --> GM2[Form edicion-producto] --> M2[Email: producto actualizado]

6 · Panel de estadísticas (solo la dueña)

El panel pide datos a una función protegida que lee los movimientos guardados. Sin rol admin, todo se rechaza (edge + función).

flowchart TD
  D[Dueña entra /dashboard/] --> EDGE{Edge: ¿rol admin?}
  EDGE -->|no| NEG[Ver dashboard-negado]
  EDGE -->|sí| PAGE[Panel /dashboard/]
  PAGE --> TOK[Renueva token
jwt(true)]
  TOK --> STAT[stats.js]
  STAT --> RF{¿rol admin?}
  RF -->|no| 403[403 no autorizado]
  RF -->|sí| BL[(Blobs movimientos)]
  BL --> JSON[Estadisticas: usuarios,
actividad, gráficos]
  JSON --> PAGE
